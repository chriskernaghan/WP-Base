Ways to vary the row

Each uses the two rows from the agencies page. The grid, type and rules are the site's own — only the row's internal structure changes.

A Measure shift Nothing moves position. The heading gets a tighter measure and the body a shorter line, so the second row breathes differently without changing the reading path. The smallest possible intervention.

B Numbered spine A mint numeral holds the left edge and turns the stack into a sequence. Works when the rows genuinely run in order; misleading when they don't.
